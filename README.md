Это репозиторий проекта второго модуля программы DataSciene от Яндекс Практикум.
Основной файл - это DS_modul_2_project.py в котором представлен анализ лояльности пользователей Яндекс Афиши.
Проект включает последовательные шаги по:
* Загрузке данных из SQL-базы
* Предобработке данных
* Исследовательскому анализу данных
